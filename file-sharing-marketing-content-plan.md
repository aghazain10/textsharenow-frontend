# TextShareNow — File Sharing Feature: Marketing & Content Plan

**Core principle throughout:** every recommendation here is additive — new sections, new pages, new content. Nothing here touches or rewrites the existing text-sharing copy that took months to rank. The one exception (the title tag) already happened before this plan; it's called out separately for monitoring, not as something to act on.

---

## 0. Monitor the title tag change first (this week)

The homepage title changed from a pure text-sharing phrase to "Share Text and Files Between Any Devices." Before layering new work on top, watch for 7-10 days:

- Daily clicks/impressions/position for "text share," "share text online," "online text sharing," "text share online" — the phrases that were climbing.
- If position holds or improves → proceed with everything below as planned.
- If position drops meaningfully and stays down after 10+ days → consider testing a title that leads with the text phrase and appends files as secondary, e.g. *"Share Text & Files Between Any Devices — TextShareNow"* is fine, but *"Share Text Between Any Devices, Now With File Sharing — TextShareNow"* keeps "Share Text Between Any Devices" fully intact as a leading phrase while still surfacing files. Worth having as a fallback, not an immediate change.

## 1. Close the content gaps first (safe, additive, do this before new blog posts)

These fill real gaps without touching anything that currently ranks — they're new sections/rows/entries, not rewrites.

- **How It Works page/section:** add a parallel file-flow explanation (Select File → Get Code/QR → Receive → Auto-Delete), styled consistently with the existing text steps. Mention the 10MB limit and 15-minute TTL explicitly.
- **About This Tool:** add one paragraph after the existing text-focused ones, introducing file sharing as an extension of the same philosophy (fast, private, no account) — don't touch the existing paragraphs.
- **Comparison table:** add 1-2 new rows — "Share images/small videos" and "File size limit" — comparing against Email/WhatsApp/QR tools, which mostly fare worse here (email attachment limits, WhatsApp compression).
- **FAQ:** add 4-5 new file-specific questions — max file size, allowed file types, file TTL vs text TTL, whether files are scanned/safe, whether videos are supported. These are genuine long-tail search phrases people type ("does whatsapp compress photos", "free file sharing no account").
- **Use Cases section:** add one new card — e.g. "Sharing a Screenshot or Quick Photo" — alongside the existing four, matching their tone.

## 2. New blog content — distinct keyword territory, not cannibalization

These target searches you currently don't compete for at all, so they're pure upside:

1. **"How to Send a Photo Without Losing Quality (No WhatsApp Compression)"** — targets a very real, commonly searched frustration (WhatsApp/Messenger compress images hard). Natural fit for your new feature, and an angle your text-sharing content never touched.
2. **"Free Temporary File Sharing: How It Works and When to Use It"** — targets "temporary file sharing," "free file sharing no account," genuinely new search territory adjacent to your existing "online text sharing" work but not overlapping it.
3. **"How to Send a Small Video Without Email Attachment Limits"** — most email providers cap attachments at 25MB; this is a real, specific pain point matching your ≤10MB video support honestly (be upfront that it's for small clips, not full videos — accuracy here matters for trust).
4. **"Screenshot to Second Device in Seconds: A Faster Way Than AirDrop or Email"** — ties back naturally to your existing AirDrop-alternative content, giving you an internal link opportunity from an already-decent-performing post into new file-sharing territory.

Keep the same author byline and varied-structure approach from your existing posts — no new template uniformity to worry about.

## 3. Marketing — revisit Product Hunt, this time on stronger footing

**This is a real reconsideration, not a repeat.** Your last PH attempt correctly wasn't eligible for a fast relaunch (QR code + a counter were UI-level changes, explicitly excluded by PH's own policy). File sharing is different: PH's own examples of *qualifying* significant updates include "new functionality," and a whole new upload/download flow with its own storage backend is a legitimate new capability, not a UI tweak.

- **Check PH's relaunch eligibility directly** (or ask their support) before assuming — don't guess a second time.
- **If eligible, execute properly this time**: schedule the launch, and this time actually mobilize your network in the first hour — the single biggest lesson from the last attempt (1 upvote, zero promotion).

**Other channels, lower effort:**
- **Update your AlternativeTo and SaaSHub listings** to mention file sharing — most directories let you edit an existing listing, which can re-surface it to browsers/algorithms without a full relaunch.
- **A short "we added file sharing" post** on Reddit (r/SideProject, r/InternetIsBeautiful) — genuine update posts perform reasonably and don't need PH's launch-day mechanics.
- **New backlink outreach targets**: search for "best free temporary file sharing tools" and "best pastebin alternatives" roundups (same outreach pattern as the Tailscale email) — file sharing gives you a new, legitimate reason to pitch inclusion in a different set of roundup articles than your text-sharing angle could reach.

---

## 4. What NOT to do

- Don't rewrite the existing hero subtitle, About paragraphs, or any currently-ranking blog post to fit files in — add alongside, never replace.
- Don't chase "file sharing" as a standalone head-term keyword the way we did with "online text sharing" — that market is dominated by much bigger, established players (WeTransfer, Smash, etc.) with genuine infrastructure advantages. Stick to the specific, honest angles above (small files, quick device-to-device, no-account) where your actual product genuinely wins.
- Don't inflate the file size/type capabilities in marketing copy beyond what's true (10MB, images + small video) — accuracy protects the trust signals we've spent months building for the AdSense/credibility side of things too.
